# SysSpector Windows 使用说明

## 简介

SysSpector 是一个用于收集系统详细信息的工具，支持收集 Windows 系统的硬件、网络、温度等数据。

## 文件说明

- `SysSpector.exe` - 主程序，用于收集系统信息
- `collect_info.bat` - 批处理文件，用于收集更全面的系统信息

## 使用方法

### 方法一：直接运行主程序

双击运行 `SysSpector.exe`，程序会收集系统信息并输出为 JSON 格式。

### 方法二：使用批处理文件

1. 右键点击 `collect_info.bat`，选择"以管理员身份运行"
2. 批处理文件会自动收集系统信息，并保存在 `SysInfo` 目录中
3. 收集完成后，按任意键退出

## 收集的信息包括

- 系统基本信息（CPU、内存、磁盘等）
- 网络配置（IP地址、WiFi信息、路由表等）
- 温度信息（如果系统支持）
- 进程和服务信息

## 注意事项

- 部分功能需要管理员权限，建议右键选择"以管理员身份运行"
- WiFi 详细信息需要使用无线网卡并已连接到 WiFi 网络
- 温度信息在某些系统上可能无法获取
- 如果遇到问题，请查看日志输出
